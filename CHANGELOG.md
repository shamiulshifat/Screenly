# Changelog

All notable changes to this project are documented in this file.

## [0.1.0] - 2026-08-27

### Added

- Native macOS recorder app shell and runtime controller
- Screen recording flow with start/pause/resume/stop
- Microphone/system audio capture and meter
- Camera discovery, preview, and overlay effects
- Compact in-recording controls and draggable camera bubble
- Metadata export and `.screenly` project bundle
- Save location configuration and recording library UI
- Global hotkeys and HUD notifications
- Packaging/release helper scripts and launch checklist
